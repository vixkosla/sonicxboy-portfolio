# Как воспроизвести подобный WebGL-сайт

Это руководство описывает не копирование личности SonicXBoy, а устройство
переиспользуемой системы: SSR-оболочка Astro, React Three Fiber сцена, одна
детерминированная хореография, мобильная режиссура камеры и финальный переход из
WebGL-объекта в обычный HTML-интерфейс.

## 1. Запуск исходника

Нужны Node.js `>=22.12 <23` и pnpm `11.11.0`.

```bash
git clone https://github.com/vixkosla/sonicxboy-portfolio.git
cd sonicxboy-portfolio
corepack enable
pnpm install --frozen-lockfile
pnpm dev
```

Основные локальные адреса:

```text
http://localhost:4321/                         русская версия
http://localhost:4321/en/                      английская версия
http://localhost:4321/?plasma-preview=card     сразу финальная карточка
http://localhost:4321/viewports/               страница проверки размеров
```

Production-проверка:

```bash
pnpm build
pnpm preview
```

Astro собирает полностью статический сайт в `dist/`; серверный рантайм не нужен.

## 2. Карта системы

```text
HomePage.astro
├── SEO, JSON-LD, RU/EN shell
├── бренд, заголовок, технологические метки
├── адаптивная композиция
└── светлая рукописная карточка
    └── HeroScene.tsx (React island)
        ├── R3F Canvas и общие часы
        ├── LayeredAssembly
        ├── SpinSimulation
        ├── DischargeScheduler
        ├── FireEffect / plasma shaders
        ├── ReactorMetamaterial
        ├── MobileCameraStory
        └── физическая панель → HTML card
```

Главный принцип: объектная хореография, камера и DOM не являются тремя независимыми
анимациями. Они читают согласованные часы и передают внимание друг другу.

## 3. Сначала замените личность

Перед публикацией производной версии замените:

- `src/components/BrandMark.astro` — эмблему;
- `src/i18n.ts` — имя, заголовки, RU/EN-тексты, контакты и URL репозитория;
- `src/layouts/HomePage.astro` — JSON-LD, социальные профили и Open Graph;
- `public/favicon.*` и `public/og.png` — изображения бренда;
- `public/llms.txt` — машинное описание автора и реальных услуг;
- `astro.config.mjs` и `public/robots.txt` — production-домен.

Не оставляйте чужие кейсы, образование, географию или контакты. Открытый код даёт
право переиспользовать реализацию, но не превращает личную биографию в шаблонную.

## 4. Дизайн карточки

Палитра локализована внутри `.reactor-card` в `HomePage.astro`. Начинайте с токенов,
а не с массовой замены цветов по файлу:

| Токен | Значение | Роль |
| --- | --- | --- |
| `--card-ivory` | `#fffdf4` | белая подсветка и текст на тёмно-зелёных кнопках |
| `--card-paper` | `#f4f3e7` | основа светлого пергамента |
| `--card-ink` | `#123f2b` | основной тёмно-зелёный текст |
| `--card-green` | `#176b45` | малахитовый акцент |
| `--card-green-deep` | `#073c28` | глубокие контуры и CTA |
| `--card-gold` | `#c7a247` | золото линий и контактов |
| `--card-gold-light` | `#ead99b` | светлое золото |

Заголовок разбит на буквицу и оставшийся текст только визуально. Полная строка
сохраняется в `aria-label`, поэтому декоративное деление не ломает чтение экранными
дикторами.

Шрифты поставляются локально через Fontsource:

- `Ponomar` — заголовок, буквица и номера мобильных листов;
- `Old Standard TT` — длинный читаемый текст.

Каждый текстовый лист после загрузки шрифтов бинарным поиском получает максимальный
размер, который помещается в его реальную высоту. Измерение запускается повторно через
`ResizeObserver`. Не заменяйте это одним `clamp()`, если хотите сохранить крупный текст
при разной длине локализаций.

## 5. Хореография объектов

Полная спецификация находится в `docs/animation-choreography.md`. Последовательность:

1. 26 элементов прилетают по предвычисленным quintic Bézier траекториям.
2. Собранный куб перекатывается через ребро и поднимается на угол.
3. `SpinSimulation` разгоняет и тормозит тело фиксированным шагом.
4. Элементы расходятся как классы симметрии, а не как независимый шум.
5. Классы сходятся в сферическую voxel-оболочку.
6. Плазма и проводники превращают оболочку в реактор.
7. Выбранная панель физически движется к плоскости экрана.
8. В её финальной проекции появляется HTML-карточка.

Если нужна другая история, сначала меняйте смысл фаз и их длительности, затем
траектории, и только после этого камеру. Попытка одновременно двигать всё обычно
разрушает причинность и визуальный вес.

### Правила горячего кадра

- Не создавайте `Vector3`, `Quaternion`, `Matrix4`, `Color` и массивы внутри
  `useFrame`.
- Повторяющуюся геометрию храните в `InstancedMesh`.
- Не снимайте delta-clamp с фиксированного интегратора.
- Предвычисляйте LUT траекторий и переиспользуйте временные объекты.
- После изменения последней фазы отдельно просматривайте последнюю секунду.

## 6. Мобильная камера

`src/lib/MobileCameraStory.ts` содержит независимый режиссёр камеры. Одна точка
описывает часы, момент прихода, продолжительность перелёта, цель и смещение камеры.
Портретный телефон получает последовательность крупных и общих планов; десктоп и
landscape сохраняют статичную композицию.

Отладочные точки работают локально:

```text
/?camera-story=arrival
/?camera-story=outer-orbit
/?camera-story=ignition
/?camera-story=reactor
/?camera-story=handoff
/?camera-story=motion:15.89
```

Полный сюжет и контрольные времена — в `docs/mobile-camera-story.md`.

## 7. Адаптивность

Здесь используются три разные композиции, а не один уменьшающийся десктоп:

- portrait mobile — режиссируемая камера и горизонтальный pager из трёх листов;
- короткий landscape — информация становится прокручиваемой правой панелью;
- desktop — три текстовые колонки и статичный обзор сцены.

Минимальная матрица ручной проверки:

```text
320 × 568
360 × 800
390 × 844
414 × 896
1024 × 768
1440 × 900
```

На каждом размере проверьте отсутствие горизонтального overflow документа, доступность
строки действий, загрузку обоих шрифтов и `scrollHeight <= clientHeight` у каждого
листа. Проверьте RU и EN отдельно: одинаковое количество символов не означает
одинаковую геометрию текста.

## 8. Контекст для ИИ-агента

Рекомендуемый порядок чтения:

1. `public/source-kit.json` — быстрая машинная карта;
2. `AGENTS.md` — технические ограничения;
3. `docs/animation-choreography.md` — объектная драматургия;
4. `docs/mobile-camera-story.md` — камера;
5. текущие исходники затрагиваемого модуля.

Для VS Code уже подготовлен `.vscode/mcp.json`. Он запускает официальный
`@modelcontextprotocol/server-filesystem@2026.7.10` и разрешает доступ только к
текущему workspace. Сервер содержит как читающие, так и изменяющие инструменты;
подтверждайте запись только когда действительно хотите менять клон.

Для другого MCP-клиента замените путь в примере из README на абсолютный путь к своему
клону. GitHub token для чтения локального исходника не нужен.

## 9. Публикация

Перед деплоем:

```bash
pnpm install --frozen-lockfile
pnpm build
git diff --check
```

Затем опубликуйте `dist/` на Vercel, Netlify, Cloudflare Pages или любом статическом
хостинге. После смены домена обновите canonical URL, sitemap, robots, Open Graph,
JSON-LD, `llms.txt` и `source-kit.json` одной операцией.

## 10. Что делает версию действительно своей

- своя идея трансформации вместо замены цветов у готовой сцены;
- собственная траектория внимания и смысл каждого плана;
- собственная типографика и ритм текста;
- реальные услуги, проекты и контакты;
- проверенная производительность на целевых устройствах;
- честное указание исходной лицензии и авторства базового кода.

Код можно форкнуть за минуту. Хорошая производная начинается там, где появляется
новая драматургия, а не только новый логотип.
